are consolidated into complete compiler routines. Use the current path shown
above each list. Exact former sources are retained in the R1912 research archive.

Core APIs retain old compatibility modules, with explicit imports for original
tape-run semantics. See r1912-core-preservation-review.txt for that separate split.
