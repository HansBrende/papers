1. EXACT DISTANCE ON A FIXED AFFINE MATRIX LINE.
For any real 2x2 matrix b and real c,t,q,
  dist(cI+tb,cI+qb)=|t-q|*||b||.
This elementary result needs neither nilpotence nor determinant one. The proof uses existing scalarAffine_eq_smul_add and mathlib norm_smul; it does not reprove norm or matrix component machinery.

2. NILPOTENT SCALAR SPACING.
Let tr(b)=det(b)=0, u=cI+tb,v=pI+qb in SL2(R), c,p>=1/2, and g in SL2(R). Put ell=tr(bg),tau=tr(g). Suppose B>0, ||b||<=B, L>0, L<=|ell|. If
  2sigma<dist(u,v), and 3B delta<=4L sigma,
then
  delta<|(2/3)(tau+ell*t)-(2/3)(tau+ell*q)|.
The determinant-one equation already proved forces c=p=1. The argument then uses the exact distance in1. It samples exact approximants: no epsilon subtraction is needed for this scalar spacing step. Approximation error still must be charged in the later actual-word transfer.

3. SOURCE-PRESERVING SCALAR SAMPLE WITH BOTH CARDINALITY BOUNDS.
