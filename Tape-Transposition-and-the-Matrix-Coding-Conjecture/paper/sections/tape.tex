\section{From block codes to whole rows}\label{sec:tape}

A block node may compute any function of its attached rows and incoming messages. The argument below uses this
causal determination, not a shared transition table. The block graph is first realized inside a walk dependency
graph so that the depth reduction applies to its actual edges.

\begin{theorem}[Theorem T: the Matrix Coding Conjecture implies the Tape Coding Conjecture]\label{thm:T}
\formal{WholeRowTCC.lean}{BlockTCC.robustNoCode_of_commonDeficit, BlockTCC.noCode_of_commonDeficit, BlockTCC.not_linearTimeTransposable_of_commonDeficit, BlockTCC.robustNoCode_of_normalizedTwoSidedDeficit}
\Cref{conj:MCC} implies \cref{conj:TCC}, in its robust and hence plain form. It therefore implies
the negation of \lean{Transpose.LinearTimeTransposable}, including adaptive machines. The same conclusion follows from a
common deficit for two-sided codes on symmetric reflexive relations.
\end{theorem}
\begin{outline}
Fix $k,G,c,C_0$, with $G\ge1$, and suppose a code solves complete exchange on $F$ with
$|F|\ge2^{L-C_0db}$, on a valid diagram of length at most $cL$. Write $\ell=\lceil db/G\rceil$ and
$N=\lceil T/\ell\rceil$.

\emph{Realization and cut.} On each work tape, the resident block set of a slot, including the adjacent block
retained at a crossing, is an interval of diameter at most two. Consecutive intervals share a boundary anchor. Replace each slot by twelve unit steps that
visit its interval around a common pivot. Memory edges are represented by state paths, and a chord has a
last-visit path between the corresponding intervals. Project a depth-reduction cut of this refined walk back to
slots. For any $\theta>0$ this gives $\Gamma\subseteq[N]$ with $|\Gamma|\le\theta N$ and a rank increasing across
all uncut edges, bounded by $D=\operatorname{genieDepth}(k,1,12,\theta)$.

\emph{Payment.} Record every outgoing message of a cut slot and every output bit rooted there. Profile capacities
give at most $4kG\ell$ message bits per cut slot, and there are at most $\ell$ cut-root output bits. The total bill
is therefore $(4kG+1)\ell|\Gamma|$. The network has undirected degree at most $2k+2$, so a radius-$D$ ball has at
most $(2k+3)^D$ nodes. A node sees at most two input rows. Equal cut records and equal raw values in that ball
determine an uncut output by induction on time.

\emph{Grouping.} Let $P$ be a positive integer. Discard output rows meeting more than $P$ slots; their number
satisfies $P|E|\le2N$. Every other output row has all its cones in at most $2P(2k+3)^D$ input rows. Fixing the
cut record and the exceptional input columns consequently gives whole-row code fibres on $F$, at that one window.
No correctness on inputs outside $F$ is used: message residues make the observation a total finite-valued map,
and capacity bounds make those residues exact on $F$.

\emph{Contradiction.} If a whole-row bound has exponent $a$, counting fibres gives the finite inequality
\begin{equation}\label{eq:block-invoice}
 L\le C_0db+(4kG+1)\ell|\Gamma|+db|E|+ba.
\end{equation}
Take $\eps=\delta/8$, choose $P>2(cG+1)/\eps$, and choose
$\theta=\eps/((4k+1)G(c+1))$. The bounds $N\le(cG+1)d$ and $N\ell\le(c+1)L$ make each of the cut and
exception bills at most $\eps L$. For sufficiently large $d$, the co-entropy bill is also at most $\eps L$.
The common-deficit hypothesis at the now fixed window gives $ba\le(1-\delta+\eps)L$. Thus
$L\le(1-\delta+4\eps)L=(1-\delta/2)L$, a contradiction. The first paper's robust-code consumer supplies the
adaptive conclusion. The normalized version follows from \cref{thm:N}.
\end{outline}

This proves one implication between the coding questions. No converse is asserted: a static whole-row code of
high rate need not be realizable as a causal code on a tape diagram.
