NEW R1868 RESULTS
1. levelCharge(V,w,n) is the sum of V(w++u) over ALL B-ary suffixes of
   length n. Mathlib Fin.consEquiv proves its exact child recurrence.
   If rho>=0 and sum_b V(w++[b])<=rho*V(w), then
     levelCharge(V,w,n)<=V(w)*rho^n.
   V>=0 and rho<1 imply summability over every descendant address, using
   mathlib List.equivSigmaTuple and summable_sigma_of_nonneg.
2. For any node w and depth h, the sum of descendant charges with relative
   depth at least h is <=V(w)*rho^h/(1-rho). The same holds for any finite
   collection of those suffixes. This follows from imported geometric sums,
   summable indicators, sigma-sum rearrangement and finite-sum comparison.
   No prior finite-depth cutoff is needed for these charge bounds.
3. assigned_tick_bound: let S be a finite set of actual execution ticks and
   owner(t) its node address. If each node owns at most a*V(node) ticks,
   and every tick in S is owned at depth>=h, then
     |S|<=a*V(root)*rho^h/(1-rho).
   The proof sums the actual ownership fibres using mathlib cardinality
   identities. deep_assigned_tick_bound derives the same bound for the
   filtered deep ticks from the budget for the ENTIRE execution set.
4. subtree_assigned_tick_bound: ticks whose owner has prefix w total at
   most a*V(w)/(1-rho). The proof identifies each suffix-owner fibre with
   the actual original fibre at w++u; unrelated ticks cannot be charged.
5. card_fin_time_interval counts exactly the integer ticks in[A,E) inside
   Fin T, giving E-A when E<=T. contiguous_call_duration_bound therefore
   bounds an actual contiguous call interval whenever its membership is
   equivalent to belonging to that node's descendant ownership fibres.
6. finite_addresses_lt_depth proves the set of B-ary addresses at depth<h
   finite, independently of execution length, using mathlib finite tuple
   images and finite unions. Together with fixed J, shallow stage keys form
   a fixed finite family for later limit extraction.
7. stage_clock_own_ticks: label:Fin T->List(Fin B) x Fin J assigns EVERY
   tick exactly one node and own-stage index. Stage endpoints A(w,j),E(w,j)
   satisfy E<=T and the exact equivalence
     A(w,j)<=t<E(w,j) iff label(t)=(w,j).
   Then the actual number of ticks owned by w is exactly
     sum_j (E(w,j)-A(w,j)).
   These hypotheses include all work ticks; no operation category is omitted.
8. stage_clock_deep_work_bound derives the geometric deep-work bound from
   those exact stage intervals and their total own-stage budget<=a*V(w).
   stage_clock_total_time_bound gives T<=a*V(root)/(1-rho).
   stage_clock_call_duration_bound gives a*V(w)/(1-rho) for each actual
   contiguous call described by the prefix-ownership equivalence.
9. stage_clock_shallow_coverage identifies ticks covered by stages at depths
   <h with ticks whose owner has depth<h. stage_clock_shallow_deficit proves
     T - number_of_ticks_covered_by_shallow_stages
       <= a*V(root)*rho^h/(1-rho).
   This is the actual finite-clock precursor to208.1 and limiting coverage;
   it does not assume a geometric coverage defect as an extra hypothesis.
10. Root bounds V(root)<=C*P yield the written a*C*P*rho^h/(1-rho)
   estimates by ordinary monotonicity. Subsequent work still must normalize
   these finite-clock bounds, pass interval geometry to a common limit and
   prove disappearance of zero-volume subtrees and the global affine cover.
