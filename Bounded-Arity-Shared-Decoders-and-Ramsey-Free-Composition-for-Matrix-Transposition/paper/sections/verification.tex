\section{Building and verifying}\label{sec:verification}

The repository must be cloned together with its sibling paper directories so that relative Lake
path dependencies resolve. The Lean package pins Lean~4 and Mathlib to version \texttt{4.34.1}.
From the paper directory
\leanfile{Bounded-Arity-Shared-Decoders-and-Ramsey-Free-Composition-for-Matrix-Transposition}, run:
\begin{verbatim}
python3 tools/lean_index.py
cd lean
lake exe cache get
lake build
lake env lean PaperAxioms.lean
cd ../paper
latexmk -pdf -interaction=nonstopmode -halt-on-error main.tex
\end{verbatim}
Running \leanfile{python3} \leanfile{tools/lean_index.py} regenerates
\leanfile{lean/BoundedArityDecoders.lean}, \leanfile{lean/PaperAxioms.lean}, and
\Cref{sec:leanindex} (\leanfile{paper/sections/leanindex.tex}) directly from the \verb|\formal| and
\verb|\lean| commands in \leanfile{paper/sections/*.tex}. Every audited declaration in \leanfile{PaperAxioms.lean} depends at most on the three standard Lean axioms
\texttt{propext}, \texttt{Classical.choice}, and \texttt{Quot.sound}; there are no \texttt{sorry},
\texttt{admit}, \texttt{native\_decide}, \texttt{unsafe}, \texttt{implemented\_by},
\texttt{extern}, or custom \texttt{axiom} declarations anywhere in the package. Some finite algebraic
and combinatorics proofs set local \texttt{maxHeartbeats} allowances for elaboration, which do not
affect statement types or kernel verification.
