\section{Building and verifying the formalization}\label{app:verification}

The Lean project is the directory \leanfile{lean/} next to this paper. It uses Lean and Mathlib, both at version v4.34.1
(\leanfile{lean-toolchain}, \leanfile{lakefile.toml}, \leanfile{lake-manifest.json}), and requires the library of the fifteenth
paper~\cite{HighRate2026} through a relative path. Through it, and the libraries it requires in turn, the build also uses the libraries
of the first, second, fourth, fifth, seventh, eighth, ninth, tenth, eleventh, thirteenth and fourteenth papers of the series, two memos
in the directories of the fourth and seventh papers, and the shared \leanfile{lean-machine/} library (including
\leanfile{LeanMachine/BlockRanking.lean} and \leanfile{LeanMachine/ThresholdRefinement.lean}). Keep the repository's
directory layout so that these sibling directories stay in place.

\paragraph{Build.} Before the first build, fetch the second paper's pinned external dependency as described in its README
(\texttt{python3 verification/fetch\_openai\_metric.py}, run in that paper's directory). With \texttt{elan} installed, run in
\leanfile{lean/}:
\begin{center}
\texttt{lake exe cache get \&\& lake build}
\end{center}
The first command downloads the compiled Mathlib cache; the second compiles \leanfile{NativeRelations} and the parts of the earlier
libraries that it uses.

\paragraph{Axioms and index.} The file \leanfile{lean/PaperAxioms.lean}, generated from the \LaTeX{} sources of this paper by
\leanfile{tools/lean_index.py}, runs \texttt{\#print axioms} on every declaration cited in this paper (\cref{app:leanindex}), both in
\texttt{NativeRelations} and in the earlier and shared libraries:
\begin{center}
\texttt{lake env lean PaperAxioms.lean}
\end{center}
Every declaration depends at most on \texttt{propext}, \texttt{Classical.choice} and \texttt{Quot.sound}. No Lean file of this
library uses \texttt{sorry}, \texttt{admit} or \texttt{native\_decide}, declares an \texttt{axiom}, bypasses the kernel via
\texttt{unsafe}, \texttt{implemented\_by} or \texttt{extern}, or raises \texttt{maxHeartbeats}. Running
\texttt{python3 tools/lean\_index.py} from the paper's root directory regenerates both \leanfile{paper/sections/leanindex.tex} and
\leanfile{lean/PaperAxioms.lean} (\texttt{--index-only} writes only the index; \texttt{--check} verifies that every cited name
resolves and that both generated files are current).

\paragraph{Where things are.} The library \leanfile{lean/NativeRelations/} has eighteen modules, all imported by the root module
\leanfile{lean/NativeRelations.lean}:
\begin{itemize}[leftmargin=1.5em]\raggedright
\item \emph{Certificates and acyclic-set tools} (\cref{sec:certificates}): \leanfile{MachineCrux.lean},
\leanfile{DichromaticCrux.lean} and \leanfile{EnvelopeCrux.lean}.
\item \emph{Two long-range heads} (\cref{sec:heads}): \leanfile{OneFreeHeadSmallExcursion.lean}.
\item \emph{Macroscopic crossings} (\cref{sec:crossings}): \leanfile{CrossingBridge.lean} and
\leanfile{MacroscopicThreshold.lean} (crossing sets, the first forms of the pullback, bridge, dichotomy and crossing theorem using
uniform block cuts and genie depth), and \leanfile{TightConstants.lean} (the common-refinement time pullback, the single-cell guarded
bridge, the constants of \cref{sec:constants}, and the main forms of \cref{lem:acyclic-cost}(b) and Theorems~D, X, S and~E).
\item \emph{Skeletons and expanding waves} (\cref{sec:skeletons} and \cref{rem:waves}): \leanfile{MacroscopicSkeleton.lean} and
\leanfile{ScaleProfile.lean}.
\item \emph{Rows to columns} (\cref{sec:demand}): \leanfile{TranspositionCut.lean}.
\item \emph{Adaptive machines} (\cref{sec:adaptive}): \leanfile{SimulatorBridge.lean} (frozen-trace deficit bounds, used with
\leanfile{TightConstants.lean}).
\item \emph{Class exclusions} (\cref{sec:classes}): \leanfile{MacroBankCrux.lean}, \leanfile{SuffixMassCrux.lean},
\leanfile{JitterMacroBank.lean}, \leanfile{AdaptiveSuffixJitterBM.lean}, \leanfile{NativeGapCriterion.lean} and
\leanfile{ZeroFreeHeadQWindow.lean}.
\item \emph{Coarse pass counting} (\cref{sec:construction}): \leanfile{CoarseGroupedPass.lean}.
\end{itemize}

\paragraph{What is not formalized.} Complete written proofs in the text, not formalized in Lean, are given for
\cref{cor:scale-separated} and \cref{prop:onecut}. Proof sketches only are given for \cref{rem:rare}, for the perfect-unshuffle
transposer realizing the $\theta=2$ parameters after \cref{cor:subcritical}, and for the exclusions of the individual schedule
families in \cref{app:catalogue} (built on the formal class theorems of \cref{sec:classes} and certificate lemmas of
\cref{sec:certificates}).

\paragraph{Constants and numerical remarks.} The script \leanfile{tools/print_constants.py} (Python~3 standard library only)
reproduces the exact rational values and scientific approximations of the constants in \cref{sec:heads,sec:constants,sec:skeletons}.
The self-contained Rust crate \leanfile{experiments/} (standard library only; \texttt{cargo run --release --offline --locked -- check} in
\leanfile{experiments/}) generates the thirty schedules, exports complete time-indexed traces, builds their exact dependency DAGs, verifies
the seven $\omega(L)$ transpose controls on the unit-vector basis and the cell-entry and write caps of the third and fourth cascades
(\cref{sec:cascades}), and reproduces the finite-size observations reported in the text, apart from the \cref{lem:R} minimum-cut costs on
rows~$1$ and~$2$ in \cref{rem:cascades} (computed by max-flow on the dependency DAGs of the traces exported by those same schedule
constructors): the crossing separator ratios and $E=L$
cycle-packing acyclic bounds of \cref{rem:numerics-crossings}, the running times, $\Lambda^*$-skeleton leg counts and single-leg crossing
expansion of \cref{rem:skeleton-limits,rem:cascades}, the coarse-pass slope products after \cref{cor:boundedpasses} (and in
\cref{sec:intro}), the multi-scale leg counts and the one-scale and two-scale closed interval-forest charges of and after
\cref{prob:multiscale}, and the fourteen numerical ``Crossings'' entries and $\omega(L)$ control checks of \cref{app:catalogue}. Those
observations are labelled as numerical throughout and no proof in the paper or the formal library depends on them.
