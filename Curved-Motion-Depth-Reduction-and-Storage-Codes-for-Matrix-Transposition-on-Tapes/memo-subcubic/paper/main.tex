\begin{abstract}
We extend the scalar storage bounds in \emph{Curved Motion, Depth Reduction,
and Storage Codes for Matrix Transposition on Tapes}. Reversible local
relations over arbitrary alphabets admit a support-dependent generating set
of size at most the matching number; a schedule uses each row at most once.
This gives ambiguity and nullity payment bounds and recovers the original
scalar theorems. Over any field, the intrinsic half bound holds at arbitrary
coordinate widths when each recovery row has at most one component of rank
above one. With unrestricted block ranks, the off-diagonal part of the
squared recovery operator pays for excess kernel dimension. If that part
vanishes, an exact quadratic rank identity holds. We also prove the required
homomorphism theorem for square-covered subcubic graphs. All numbered
results are verified in Lean. None of these additional coding hypotheses
follows from native tape geometry alone.
\end{abstract}
