1. NativeMicrocode / NativeIO / NativeReadFusion / NativeIOFusion
All existing theorem statements and every machine, instruction, transition, configuration encoding, active predicate and run definition are unchanged. The first two files only merge proof branches that perform identical rewrites. The fusion files replace repeated instruction case analyses with the underlying already-proved one-step correspondence.
The local lift functions copy all five configuration fields unchanged: control state, input position, work-tape contents, work positions, and reversed output. They merely change the machine type index; resource parameters k, q, and g remain identical. No time rescaling, extra transition, omitted transition, or new hypothesis is introduced. The effective microcode program in NativeReadFusion is frozen only for the single current step, from exactly the current scanned symbols; subsequent runs still recompute effective instructions through the unchanged step function. Consequently this reuse does not assume that the same frozen program describes later steps.

2. FiniteAffineObstruction
The original contradiction statement, including the literal hstar premise, remains unchanged. Its proof now invokes one_le_of_star_small_cuts with B=0 and obtains the required small cuts from the same existing finite-affine cut theorem for every positive theta and epsilon. The imported SatisfiesStar abbreviation expands to the original hstar statement. No extra Lipschitz, compactness, omission or interval assumptions enter this replacement. The argument concludes 1<=0 and hence False.

3. AffineApproximationObstruction
The only changed existing theorem header is AffineTimeRequired.not_bounded_affine_approximation: uniform convergence of u to P has been replaced by pointwise convergence at every point of the same closed interval. This is a weaker premise with the identical False conclusion, so it strengthens the obstruction. The approximation-error bound remains uniform and tends to zero; the change must not be described as weakening that separate error requirement. The proof transfers pointwise convergence from u to q by the existing distance squeeze, then invokes not_pointwise_bounded_covers. Both native application statements are unchanged and supply pointwise convergence via TendstoUniformlyOn.tendsto_at from their original uniform limits.

4. CoordinateCoverRefinement / SL2TraceCover
The new exists_finite_code_representatives requires only [Fintype L] for the code alphabet. It imposes neither Fintype X nor finite A nor Nonempty X. Representatives are selected from the attained range, a subtype of finite L; Classical.choice and classical equality on X do not imply a finite X. Each chosen representative carries a genuine preimage witness, so no uninhabited code fiber is selected. The empty-domain case also remains valid.
Both consumers keep their original theorem statements and original code alphabets. Their code-equality consequences, bin estimates, metric reconstruction inequalities and numerical bounds are unchanged. The new cardinality chain bounds the representative image by the finite code alphabet, exactly as the previous two duplicate proofs did. No ambient-domain finiteness has been smuggled into either covering theorem.
