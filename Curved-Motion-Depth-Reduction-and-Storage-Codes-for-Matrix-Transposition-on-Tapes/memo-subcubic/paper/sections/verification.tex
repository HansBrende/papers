\section{Building and verification}\label{sec:verification}
Clone the complete repository with sibling directories intact. The memo
uses Lean and Mathlib v4.34.1 and imports the fourth paper's package through
\texttt{../../lean}, including its dependencies on earlier and shared libraries.
In this memo's \texttt{lean/} directory run
\begin{verbatim}
lake exe cache get
lake build
lake env lean PaperAxioms.lean
\end{verbatim}
From the memo directory, \texttt{python3 tools/lean\_index.py} generates
both the declaration index and the axiom checks from the LaTeX references.
All cited declarations depend at most on \texttt{propext},
\texttt{Classical.choice}, and \texttt{Quot.sound}. No new axioms,
\texttt{sorry}, or kernel-bypassing evaluation are used. The original
paper's sources are unchanged. Build the PDF in \texttt{paper/} with
\texttt{latexmk -pdf main.tex}.

The square-covered graph theorem is proved in the library, including
the closed-component argument, ladder extension, finite base maps, and
component assembly. It is not supplied as an assumption to the final
rank theorems. The shared library supplies sparse-row rank accounting,
coordinatewise idempotent splitting, and invariant-kernel transport.
One routine elaboration, the constrained-kernel capacity sum, raises
\texttt{maxHeartbeats} to 1,200,000; this changes no logical rule.
