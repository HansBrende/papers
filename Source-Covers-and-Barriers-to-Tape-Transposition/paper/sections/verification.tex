\section{Building and checking this draft}\label{sec:verification}

The paper sources and PDF use CC BY 4.0; the Lean library uses Apache 2.0.
\Cref{def:complete-families,def:admissible-geometry,lem:family-accounting,def:clipped-shadow,lem:shadow-variation,lem:protected-phase,thm:exact-source-bank,lem:residual-source-recovery,thm:cyclic-freezing,def:fractional-core-cover,lem:interval-rounding,lem:fractional-gap,lem:anchored-erosion,thm:paid-source-cover,cor:orbit-count-deficit,prop:continuation-covers,def:joint-profile,thm:necessary-hop-tail,cor:one-exception,cor:common-envelope,cor:finite-skeleton,thm:necessary-cover,cor:uniform-cover,cor:necessary-exposure,prop:finite-sharing,thm:uniform-sharing,lem:attached-short-count}
are Lean-verified. Their cited
declarations depend only on \leanname{propext},
\leanname{Classical.choice} and \leanname{Quot.sound}. The remaining
numbered results have complete written proofs and are not formalized.
No additional axiom, admitted proof or native decision procedure is
used in the new library.

The package pins Lean and Mathlib to the repository's existing v4.34.1
versions. It requires the existing second-paper build adapter, whose
source directory points to the first paper's canonical Lean files.
It also requires the eighth paper's \path{boundedNesting} package for
actual families and the shared \path{lean-machine/} package for interval
covers, finite incidence sums, monotone patches, thin interval graphs,
protected phases, finite action orbits, uniform source banks,
shifted-grid payment, causal recovery, circular gaps, periodic stripes,
minimum fractional covers, canonical time components, weighted circular
subdivisions, anchored partition-energy bounds, profile compactness,
finite-error normalization, weighted-tail comparison and uniform gaps
from sequential exclusion, extended lower limits, power-envelope moments,
bounded upper limits, inverse-square tails and quantitative real-power tails.
The joint-profile proofs reuse Mathlib's compact products, finite-sum
limits, summability, normalized ceilings and nonnegative-series divergence.
The uniform-deficit proof reuses reciprocal limits, the squeeze theorem
and the logarithm/real-power equivalence. Common envelopes add Mathlib's
extended-nonnegative lower limits and $p$-series theorem. The supplied
family ordering is retained directly through the sequence construction.
The finite-skeleton proof instead supplies the zero profile explicitly;
its family-count consequence reuses Mathlib's natural-floor inequalities.
The reciprocal-cover proof retains actual averages through both limits
and reuses Mathlib's subsequence characterization of an upper limit.
The probability bound uses a finite indicator comparison and the existing
finite inverse-square sum estimate. The uniform mean-cover criteria reuse
Mathlib's finite Cauchy inequality, integral comparison and improper-integral
formula, followed by the existing uniform-gap adapter. A chosen family order
is retained for both the envelope and the cover budget.
The continuation suppliers reuse ordered-bank exactness, finite maximal
elements obtained by greatest time, fractional-cover feasibility, interval
oscillation and anchored erosion. Their source-bank slots include complete
older continuations, and missing exceptions are identity maps.
The complete-movement proof reuses finite interval hulls and the existing
paid-error limit, now shared with the reciprocal-cover argument. Explicit
bank-variation bounds justify the two real lower limits. The final radius
lower limit uses the extended nonnegative reals to allow divergence.
The shared-support proof reuses complete-closure maximality, residual-shift
selection, joint record/raw entropy and signed phase averaging. A finite
union of clipped grid blocks is paid once, with a bound valid for every
shift; the older bank's movement never replaces the full bank's residual
bill. Finite entropy is reused from the second paper's library.
The uniform-sharing proof retains the same original-order prefixes and
uses the generalized paid-error limit. A shared quadratic tradeoff handles
zero cost coefficients and arbitrary common good cutoffs. Mathlib supplies
extended-real scaling and the decay of positive real powers.
Readers need the whole repository, with sibling folders in place.
No source from an earlier paper is copied or modified. From \path{lean/}, run
\begin{samepage}
\begin{verbatim}
lake exe cache get
lake build
lake env lean PaperAxioms.lean
\end{verbatim}
\end{samepage}
The cache command is needed only when the pinned dependency objects
are not already available. The axiom output must contain no axioms
beyond the three listed above. No heartbeat override is needed for
the new proofs.

From this paper's top-level directory, regenerate or check the statement
index and axiom commands with
\begin{verbatim}
python3 tools/statement_index.py
python3 tools/statement_index.py --check
\end{verbatim}
The script reads the section order from \path{paper/main.tex}, checks
stable labels, proof-status markers and the corresponding proof or
outline environments, and generates the index appendix,
\path{FORMALIZATION-INDEX.md}, and \path{lean/PaperAxioms.lean}.
It does not itself verify the mathematics or execute the axiom commands.
\path{FORMALIZATION.md} records completed work and the remaining plan.

Build the PDF from \path{paper/} with
\begin{verbatim}
latexmk -pdf -interaction=nonstopmode -halt-on-error main.tex
\end{verbatim}
Resolve undefined references and citations, and inspect the rendered
pages. Earlier-paper references are pinned in \path{paper/references.bib},
and their proof status is stated where used. Public paths are relative
to this repository. Run \path{tools/check_public_paths.py} from the
repository root as described in \path{CONTRIBUTING.md} before publishing.
That scan checks portability and local-path disclosure, not theorem
correctness.
