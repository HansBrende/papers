EXACT STATEMENTS AND DEPENDENCY MAP
NEW R1876 RESULTS
1. MaskedStrideGroupSemantics proves the cellwise meaning of the existing
   paid4*S slab. At every active slot, both operands are still the original
   bank and scratch values for that group. For j<g the bank receives
      x_j XOR (a_j AND prev_j).
   The scratch receives that output in prefix mode, and the ORIGINAL x_j
   in difference mode. Outside each tape's g-cell update interval, all
   absolute cells are unchanged. Padding and physical rewind write nothing.
2. MaskedStrideScan.AtGroup tracks actual bank/scratch head positions,
   outputs of all earlier groups, the untouched future bank and the exact
   preceding-group buffer value. groups_invariant proves this for every
   full group, starting with zero-decoding scratch cells. partial_correct
   handles any last g<=S, preserves all earlier outputs and the future bank,
   and restores the scratch head. Data and masks never affect these lengths.
3. MaskedStrideBank.value_recurrence proves the standard raw-index equation
      y_n = x_n XOR (a_n AND previous_n),
   where previous_n=0 for n<S; otherwise it is y_(n-S) in prefix mode
   and x_(n-S) in difference mode. This is proved from the recursively
   defined group semantics, not supplied as an assumed executor invariant.
   result_correct proves that every j<P in the actual final bank equals
   this y_j, the bank head advances P, the scratch head restores, and all
   bank cells at/after the end of the processed bank remain unchanged.
   Here x_j is decoded from the actual initial absolute bank cell.
4. MaskedStrideExecution composes scheduled instructions BEFORE compiling
   them. full_exact/full_prefix connect full groups and their intermediate
   states to the existing slab. schedule_exact and native_run execute all
   floor(P/S) full groups plus one last P%S group in a SINGLE native program,
   then halt, with no unpaid call transitions. If P%S=0, the empty final
   slab still executes and is charged. For positive S the exact processing
   duration is N=4*S*(floor(P/S)+1). ticks_le gives N<=8*P when S<=P.
   state_count gives q+1=4*(N+1), using the existing public-clock compiler,
   two work tapes, and the existing five-symbol work alphabet. This pays
   the arbitrary public masks through nonuniform transition tables; it
   does not read them from a free data oracle.
