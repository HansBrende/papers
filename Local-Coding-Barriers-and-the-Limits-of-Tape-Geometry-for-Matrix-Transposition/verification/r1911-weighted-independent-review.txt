ENTROPY AND ZERO CASES
The new fiber-card inequality is valid for arbitrary nonnegative weights
without normalization. Each attained fiber has at least the current input,
so its reciprocal size is strictly positive. An empty fiber contributes zero
to its comparison budget. Conditional Gibbs only expands logarithms where
the source weight is positive; zero source weights require no logarithm
positivity. Hence no implicit full-support, independence, or positive-fiber
hypothesis is introduced.

The aggregate theorem explicitly requires total source mass one. Its
pushforward leaf weights retain both nonnegativity and total mass one.
Normalization is used where the constant P*log(2) is extracted. Positive
leaf probability implies a nonempty fiber, so the existing geometric
volume positivity and count inequalities apply. Zero-mass leaves are
handled separately. An empty input type cannot satisfy sum(w)=1; this
exclusion is semantic, not an extra unexplained Nonempty premise.

The aggregation algebra is sound:
H(X) <= H(L) + E log |fiber(L)|;
2 E log |fiber(L)| <= E log volume(L) + E loss*log(2);
H(L) <= H(Z) + P log(2) - E log volume(L);
H(L) <= H(Z) + E charge*log(2).
Adding these yields the stated weighted bound, with coefficient two on
the helper entropy. All expectations use the same supplied source law.

PROTOCOL / GRAPH / TREEWIDTH SCOPE
Finite-family truncation is unchanged and needs execution only on F.
Correctness and separation are still required on all of F, including any
zero-weight inputs; the new theorem should be described as arbitrary laws
on a correct family F, not as correctness merely on positive-mass inputs
within an otherwise arbitrary declared F. Choosing F to be the support
gives that usual formulation. Arbitrary finite original-row query supports
and the clique interaction graph remain unchanged. No coded-workspace
access is added. The ambient helper type remains finite in this chain.

The graph bound removes separator compatibility by the same actual-graph
component argument. The average treewidth proof uses the existing weighted
mean separator lemma, preserving the coefficient n/4 and correction alpha/2.
Only weights replace uniformWeight, D becomes P-H(X), and H(Z) is computed
under those weights. The same n>0, b>0 assumptions justify divisions.

SUPPORT RETIREMENT TO DISCLOSE
EntropyFibers.mean_log_fiberCard, an exact uniform-source identity, has
been removed. Its replacement is a more generally applicable inequality;
it does not assert that original equality for arbitrary distributions.
No remaining source consumer uses the retired identity. This is retirement
of a support result, not a weakening of any original main theorem; preserve
its baseline source in the archive and describe it as such.
