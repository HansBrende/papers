1. ARBITRARY-DISTRIBUTION TWO-STAGE TOLL
For ANY probability law X on a correct family F, not just its uniform law,
let Z be the attained helper and P=n^2*b. In bits:

  P - H(X) + H(Z) >= b*r*(n-r), for every 0<=r<=n;
  P - H(X) + H(Z) >= b*floor(n^2/4).

Weights may vanish and be correlated. The ambient helper type can be infinite;
its attained finite subtype is used. Correctness is exact on F, and the same
deterministic two-stage primitive architecture is retained. The original uniform
D=P-log2|F| statements and range/density bounds remain available unchanged.
This broadens input laws, not the excluded computational architecture, and does
not improve the quarter coefficient.

Lean: TwoStageHelper.helper_entropy_deficit_bound_of_distribution and
quarter_helper_entropy_deficit_bound_of_distribution.

A shared fiber-cap lemma proves H(p)<=H(f_*p)+(sum p)log C for C>0 whenever
every fiber has cardinality<=C, for arbitrary nonnegative weights. This
unnormalized bound uses the development's entropy functional and natural logs.
The existing conditional Gibbs lemma no longer assumes normalization. Two adaptive aggregation call sites
reuse this more general lemma without changing their conclusions. The natural
exponent decomposition is shared between counting and entropy proofs.
These abstract entropy facts are standard tools; no novelty is claimed for them.

2. UNIVERSAL PADDING RESOURCE FORMULAS
The existing exists_uniform_paid_padding endpoint now chooses absolute integers
A,H,K0,E BEFORE the payload machine M. Besides every previous runtime, exact
output, actual halt, zero-slack CutIneq and full-limit conclusion, it supplies

  number of states(M') = H + number of states(M),
  tapes(M') = K0 + (tapes(M)+E)*max(1,Nat.size(M.g)),
  cellBits(M') = 3.

The constructed machine uses five work symbols; cellBits=3 is the bit charge
exposed by the endpoint. M.g is one less than the source work-alphabet size.
State counts are q+1.
A is the universal additive linear runtime coefficient. The formulas follow
from the existing fixed-resource compiler contracts, with no new machine
construction or extra assumption. Constants are existential, not a practical
numerical table. No finite-state uniformity claim has been dropped.
Lean: TransposeFollowup.PaidPadding.exists_uniform_paid_padding, in the
UnconditionalPaidPadding module.

3. SHARPER PATH/CYCLE XOR CONSTANT
For n>0, the five real-valued path/cycle endpoints now give

  B >= P - b*n*sqrt(8*n),

improving the real error coefficient from 3 to 2*sqrt(2). Arbitrary nonlinear
row bijections, fixed singleton/pairwise XOR packets, all-input correctness
and the same graph-locality/embedding hypotheses are retained.

The proof uses k=floor(sqrt(n/2)) and keeps the exact ball cap 2k-1; n=1 is
handled separately. The existing natural-number bound with error
3*b*n*floor(sqrt(n)) is preserved unchanged because it can be sharper at some
small n. No new imports or public declarations are needed. This adds 21 lines
and improves a finite constant, not the asymptotic order or architecture scope.
Lean: RecodedXorCode.linear_ball_broadcast_lower_bound and its four graph
specializations in XorPathCycleBound.
