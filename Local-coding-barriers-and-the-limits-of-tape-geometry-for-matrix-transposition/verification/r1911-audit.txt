1. ADAPTIVE SEPARATORS FOR ARBITRARY LAWS
Let X have any normalized nonnegative probability law w on the finite correct
family F. Let P=n^2*b, Z=helper(X), and D_w=P-H_w(X), with entropy in bits.
For the same deterministic adaptive original-row strategy and any separator
chosen from the helper and completed public transcript, put
  L(X)=n*b*|S(X)|+b*sum_C |C|^2,
where C ranges over components of the actual interaction graph minus S(X).
Then
  E_w[length] >= P - E_w[L] - 2D_w - 2H_w(Z).
For n,b>0, if E_w[length]<=(1-epsilon)P, put
  alpha=max(epsilon-2(D_w+H_w(Z))/P,0).
Then
  E_w[treewidth] >= (n/4)*alpha^2 + alpha/2 - 1.

Weights may vanish; no independence or uniformity is required. The protocol
must be exactly correct on all of the declared F, including zero-weight
members; alternatively F may be chosen as the support. Query supports may
contain any finite number of original rows, with each support contributing
a clique. Public control, original-row access, and the finite helper type
remain as before. There is no new permission to query coded workspace.
This widens allowed input laws, not the excluded computational architecture,
and does not improve the coefficients. All original uniform main theorem names and
statements are retained as direct specializations.

Main Lean declarations:
  TransposeFollowup.graph_expected_separator_bound_of_distribution
  TransposeFollowup.average_treewidth_lower_bound_of_distribution
Intermediate RowCode, strategy, aggregation and integer-threshold endpoints
also have arbitrary-law versions. The uniform implementations reuse these.

The common entropy estimate, for ANY nonnegative finite weights p, is
  H(p) <= H(f_*p) + sum_a (f_*p)(a)*log|f^(-1)(a)|.
It uses natural logs and needs no normalization. Apply conditional Gibbs
with q(x)=1/|f^(-1)(f(x))|; occupied fibers have q-mass one and empty fibers
mass zero. Averaging the existing leaf inequality and the unchanged volume
and prefix-code budgets proves the weighted adaptive result. This abstract
entropy tool is standard mathematics; no literature novelty is claimed.

  for each head t and each x in [0,H], u_n(t,x) -> P(t,x),

not a claim that arbitrary almost-everywhere or merely average error suffices.

already-proved uniform limits. Their theorem statements do not change.
