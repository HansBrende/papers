\section{Building and checking the proofs}\label{sec:verification}

The paper sources and PDF use CC BY 4.0; the Lean library uses Apache 2.0.
All 32 numbered results and 6 numbered definitions
are Lean-verified. Their cited
declarations depend only on \leanname{propext},
\leanname{Classical.choice} and \leanname{Quot.sound}.
No additional axiom, admitted proof or native decision procedure is
used in the new library.

The package pins Lean and Mathlib to the repository's existing v4.34.1
versions. It requires the existing second-paper build adapter, whose
source directory points to the first paper's canonical Lean files.
It also requires the eighth paper's \path{boundedNesting} package for
actual families and the shared \path{lean-machine/} package for finite
combinatorics, source-bank accounting, causal recovery, flows, weighted
paths and analytic limits. Its README lists the reusable modules.
The mathematical reuse and exact scope are recorded in
\cref{sec:formalization}; the generated index in \cref{sec:theorem-index}
identifies all cited declarations. These dependency records complement
the builds and axiom audits; they do not replace either check.

Readers need the whole repository, with sibling folders in place.
No source from an earlier paper is copied or modified. From \path{lean/}, run
\begin{samepage}
\begin{verbatim}
lake exe cache get
lake build
lake env lean PaperAxioms.lean
\end{verbatim}
\end{samepage}
The cache command is needed only when the pinned dependency objects
are not already available. The axiom output must contain no axioms
beyond the three listed above. No heartbeat override is needed for
the new proofs.

\begin{samepage}
From this paper's top-level directory, regenerate or check the statement
index and axiom commands with
\begin{verbatim}
python3 tools/statement_index.py
python3 tools/statement_index.py --check
\end{verbatim}
\end{samepage}
The script checks labels, formal-status markers and proof environments,
and generates the declaration appendix, \path{FORMALIZATION-INDEX.md} and
\path{lean/PaperAxioms.lean}. It does not verify proofs or execute audits.
\path{FORMALIZATION.md} records the completed stages and reuse decisions.

Build the PDF from \path{paper/} with
\begin{verbatim}
latexmk -pdf -interaction=nonstopmode -halt-on-error main.tex
\end{verbatim}
Check references and citations and inspect the rendered pages. Earlier-paper
citations are pinned in \path{paper/references.bib}. Before publishing,
run the repository's public-path checks as described in
\path{CONTRIBUTING.md}; they check portability, not theorem correctness.
