EXACT STATEMENTS AND DEPENDENCY MAP
NEW R1875 RESULTS
1. ScheduledNativeIO compiles a public schedule sigma_i of native IO
   microinstructions with a fixed finite local mode M. The compiled labels
   are Fin(N+1) x M. All scheduled steps must be active; this is proved for
   the concrete routines, not assumed of arbitrary programs without checking.
   The clock advances exactly once per scheduled instruction and halts at N.
   NativeIOEmbedding reuses existing instruction wiring, and NativeIO's
   trace_stepN gives exact original-machine execution. No new tape simulator.
   native_prefix covers every n<=N, with the full configuration and every
   absolute head position. native_run_and_halt proves N actual transitions
   and the native halt; native_state_count proves q+1=(N+1)*|M|.
   trajectory_add/congr compose prescribed schedule segments without free
   semantic operations. Public schedule selection is compile-time nonuniform
   information; local data is confined to the stated finite mode and tapes.
2. MaskedStrideCell reads bank tape0, then buffer tape1, then writes/moves
   both heads. Exactly THREE native transitions implement
       y = x XOR (a AND previous).
   Prefix mode stores y back into the same buffer cell; difference mode
   stores the ORIGINAL x. Both old values are read before either overwrite.
   Two Boolean values suffice as local mode (four values). The standalone
   three-step instance uses two work tapes, the existing five-symbol alphabet
   and16 states. No zero-cost read, write or movement is supplied.
   result_cells proves exact absolute tape contents, including preservation
   of every other cell, and result_positions proves both heads advance one.
   Blank/nondata buffer symbols decode as zero; data symbols decode exactly.
3. MaskedStrideGroup gives each group S slots of three ticks, followed by
   S physical left moves of the scratch head. The first g<=S slots execute
   the masked cell. The remaining slots make two stationary steps and move
   only the scratch head right once, without reading/writing the bank.
   This is a single-buffer implementation: reading the previous-group bit
   before replacing it avoids a second alternating buffer.
   process_exact proves the exact iteration of the local update/padding.
   group_exact/native_group prove precisely4*S actual native transitions
   and halt in the explicit result configuration. All public masks vary
   arbitrarily by slot. Raw IO and final buffer clearing are not included.
4. group_positions proves BOTH physical head positions at every scheduled
   tick n (and native_prefix transfers it to native prefixes n<=4*S).
   With initial bank/scratch positions b0,b1, during0<=n<=3*S:
       bank=b0+min(floor(n/3),g), scratch=b1+floor(n/3).
   During3*S<=n<=4*S:
       bank=b0+g, scratch=b1+S-(n-3*S), provided g<=S.
   Thus the bank advances exactlyg, scratch restores exactly, and partial
   groups cost the same4*S slab as full groups. Data values never enter
   these head-position formulas. These are the concrete paths needed for
   both zero and positive normalized-stride cases.
