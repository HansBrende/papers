# Lean library `NativeRelations`

The formalization of *Oblivious Linear-Time Tape Transposers Need Macroscopic Crossings* (Lean and Mathlib v4.34.1). It requires the
fourteenth paper's library `BoundedStackDepth` and the fifteenth paper's library `TapeStorageRates` by relative paths, and through them
the earlier libraries of the series and `../lean-machine/`, so the sibling directories of the repository must be in place. Declarations
are in the namespace `NativeRelations`.

## Modules

The root module `NativeRelations.lean` imports all eighteen modules.

| section | modules |
|---|---|
| certificates and acyclic-set tools (§3) | `MachineCrux` (`SConeOf`, `MachineCruxAt`, `machine_crux_excludes`), `DichromaticCrux` (acyclic-set bounds for storage and index codes), `EnvelopeCrux` (cut-cruxes, ball-avoidance relations, envelopes, windows, step-invariant potentials, block-ranking cuts via `LeanMachine.BlockRanking`) |
| two long-range heads (§4) | `OneFreeHeadSmallExcursion` (Theorem H and Corollary 4.2: slab autonomy, two macroscopic work heads, off-carrier vertex expansion) |
| macroscopic crossings (§5) | `CrossingBridge` and `MacroscopicThreshold` (crossing steps `crossingLowerEtaSteps`, two-cut covering of non-crossing large hops, phase-exit dichotomy, and the genie/block-cut first forms of the pullback, bridge, Theorem D and Theorem X), `TightConstants` (common-refinement pullback via `LeanMachine.ThresholdRefinement`, single-cell guarded bridge, explicit constants of §5.1, and the main tower-free forms of Lemma 3.5(b) and Theorems D, X, S and E) |
| skeletons and waves (§6, Remark 8.3) | `MacroscopicSkeleton` (grid milestones, coarse skeletons, crossing-capable characterization, leg confinement), `ScaleProfile` (disjoint expanding-wave time bounds) |
| rows to columns (§7) | `TranspositionCut` (Lemma R and the bichromatic colouring criterion, Theorem 7.2) |
| adaptive machines (§8) | `SimulatorBridge` (frozen-trace cone and ball-avoidance deficit bounds; heavy-trace and simulator theorems in `TightConstants`) |
| class exclusions (§9) | `MacroBankCrux` (Theorem B), `SuffixMassCrux` (Theorem 9.3), `JitterMacroBank` and `AdaptiveSuffixJitterBM` (Theorem J, whole-run and suffix forms), `NativeGapCriterion` (Theorem G and Corollary 9.6), `ZeroFreeHeadQWindow` (Theorem Q) |
| coarse pass counting (§10.4) | `CoarseGroupedPass` (Theorem 10.3, Corollary 10.4, and the θ = 2 grouped-inequality sharpness clauses) |

Every declaration cited in the paper is indexed by module in `../paper/sections/leanindex.tex` and checked with `#print axioms` in
`PaperAxioms.lean` (generated by `../tools/lean_index.py`); each depends at most on `propext`, `Classical.choice` and `Quot.sound`.

## Building

From this directory: `lake exe cache get`, then `lake build`, then `lake env lean PaperAxioms.lean`. Locally, `.lake/packages` may be a
symbolic link to a sibling library's packages at the same revisions; `.lake/` is ignored by Git.
